# Coffee Break

#### Video Demo: https://youtu.be/N5JXtMbuV_I

#### Description:

Coffee Break is a fast-paced arcade game inspired by classic bar-serving games such as Tapper.

The player takes the role of a barista serving customers across multiple lanes. Customers must be served before they become impatient, and the player earns tips for successful service. As the game progresses, the difficulty increases through faster customer movement and more demanding gameplay.

This project was developed using Lua and the LÖVE2D framework as the final project for Harvard's CS50 course.

The game includes score tracking, customer management systems, pause functionality, game over states, and support for mobile devices.

The main goal of the project was to create a small but complete arcade experience that can be enjoyed in short play sessions while still providing challenge and replayability.
